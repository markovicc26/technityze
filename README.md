# Technityze

Two-person studio site - websites, mobile apps and SEO.

## Stack

Next.js 16, React 19, TypeScript, Bootstrap 5, GSAP, Framer Motion, Matter.js, Lenis.

## Develop

```bash
npm install
npm run dev
```

Site runs at http://localhost:3000.

## Deploy

Auto-deployed to Vercel on push to `main`.
